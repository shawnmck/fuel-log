One-time setup

1
Go to console.cloud.google.com and create or select a project.
2
Enable the Google Sheets API and Google Identity Services.
3
Create an OAuth 2.0 Web Client ID. Add this page's URL as an authorized JavaScript origin.
4
Paste your Client ID below. Your Spreadsheet ID is the long string in its URL.
